# 자기소개서 문체 가이드

> 핵심 톤: **행동은 분명하게, 기여는 겸손하게**  
> 목적: 기업별 자기소개서 작성 시 문장 톤, 분량, 구조, 표현 금지선을 일관되게 유지합니다.

## 1. 기본 원칙

### 두괄식

첫 문장에서 결론을 말합니다. 배경 설명으로 시작하지 않습니다.

나쁜 예:

> 플랜트 시운전 당시 여러 문제가 있었고, 저는 그 과정에서 많은 것을 배웠습니다.

좋은 예:

> 저는 맡은 설비의 문제를 끝까지 확인하는 책임감으로 펌프 과전류 트립을 해결한 경험이 있습니다.

### STAR 구조

모든 경험 문항은 자연스럽게 아래 흐름을 포함합니다.

| 요소 | 작성 기준 |
|---|---|
| Situation | 어떤 상황이었는지 짧게 |
| Task | 해결해야 할 문제가 무엇이었는지 |
| Action | 내가 실제로 한 행동 |
| Result | 결과와 배운 점 |

### 미사여구 최소화

과도한 수식보다 실제 행동, 근거, 결과를 우선합니다.

- 사용 권장: `분석했습니다`, `검토했습니다`, `조율했습니다`, `확인했습니다`, `도출했습니다`, `적용했습니다`
- 사용 제한: `혁신했습니다`, `완벽히 해결했습니다`, `압도적으로 성장했습니다`, `반드시 해내겠습니다`

## 2. 문장 톤

### 행동 표현

자신이 한 일은 능동적으로 씁니다.

- `점검 범위를 전기제어 영역까지 넓혔습니다.`
- `제상수 온도와 유량을 조작 변수로 설정했습니다.`
- `3D 모델링으로 간섭 구간을 시각화했습니다.`

### 기여 표현

입사 후 기여는 겸손하게 씁니다.

- `기여하겠습니다`
- `돕겠습니다`
- `보탬이 되겠습니다`
- `역량을 더하겠습니다`
- `반복 이슈를 줄이는 데 기여하겠습니다`

### 자신감의 기준

경험은 분명하게 말하되, 미래 성과는 보장하지 않습니다.

좋은 예:

> 이 경험을 바탕으로 입사 후에도 설비 문제를 구조적으로 분석하고, 안정적인 운영에 기여하겠습니다.

피해야 할 예:

> 입사 후 설비 가동률 100%를 반드시 달성하겠습니다.

## 3. 분량 정책

| 조건 | 기본 분량 |
|---|---:|
| 글자수 제한 명시 | 제한의 85~98% 이내 |
| 글자수 제한 없음 | 800~1000자 |
| 자유기술형/직무역량 종합 | 1000~1300자 |
| 짧은 문항/선택 문항 | 500~800자 |

분량은 절대 목표가 아닙니다. 설명이 충분하면 짧아도 됩니다. 단, 글자수 제한이 없고 기업이 자유기술형을 요구하는 경우에는 800자 미만으로 너무 가볍게 보이지 않도록 합니다.

## 4. 문항별 기본 구조

### 지원동기

1. 회사 방향과 내 직업관이 맞는 이유
2. 해당 직무가 왜 나에게 맞는지
3. 내가 가진 경험이 어떻게 기여로 이어지는지

템플릿:

> 제가 [회사/직무]에 지원한 이유는 [회사 방향]이 제가 지향하는 [직업관]과 맞기 때문입니다. 저는 [경험]을 통해 [직무 핵심역량]의 중요성을 배웠고, 이를 바탕으로 [기여 방향]에 기여하고 싶습니다.

### 직무역량

1. 직무에 필요한 역량 정의
2. 내 경험 1~2개 제시
3. 결과와 직무 연결

템플릿:

> 해당 직무에는 [역량 1], [역량 2], [태도]가 필요하다고 생각합니다. 저는 [경험]에서 문제를 정의하고, 원인을 분석하고, 개선안을 적용한 경험이 있습니다.

### 도전 경험

1. 가장 도전적인 목표 제시
2. 어려웠던 이유
3. 접근 방식
4. 결과와 배운 점

템플릿:

> 가장 도전적인 경험은 [경험]입니다. 처음에는 [어려움]이 있었지만, 문제를 한 번에 해결하려 하지 않고 [접근 순서]로 나누어 해결했습니다.

### 협업/갈등 해결

1. 이해관계 충돌 상황
2. 감정이 아닌 기준 설정
3. 시각화/문서화/회의 등 행동
4. 납득 가능한 결과

템플릿:

> 저는 먼저 감정적인 설득보다 모두가 인정할 수 있는 기준을 세우는 것이 필요하다고 판단했습니다.

### 강점/약점

강점은 확실히 말합니다. 약점은 현재 개선 중인 행동 기준까지 씁니다.

템플릿:

> 제 강점은 [강점]입니다. [경험]에서 이 강점을 발휘했습니다. 반대로 [약점]이 있었지만, 최근에는 [보완 방식]으로 개선하고 있습니다.

### 입사 후 포부

단기, 중기, 장기 구조가 기본입니다.

- 단기: 직무 기준, 설비/공정 구조, 내부 절차 습득
- 중기: 반복 이슈 감소, 데이터 기반 개선
- 장기: 직무 전문성 확장, 개선 체계 구축

## 5. 표현 규칙

### 행동 동사

| 상황 | 권장 표현 |
|---|---|
| 분석 | 분석했습니다, 비교했습니다, 검증했습니다 |
| 현장 대응 | 점검했습니다, 확인했습니다, 조치했습니다 |
| 협업 | 조율했습니다, 공유했습니다, 합의를 이끌었습니다 |
| 개선 | 도출했습니다, 적용했습니다, 개선 가능성을 확인했습니다 |
| 학습 | 학습했습니다, 익혔습니다, 적용했습니다 |

### 미래 기여 표현

| 과한 표현 | 안전한 표현 |
|---|---|
| 완벽히 장악하겠습니다 | 빠르게 익히겠습니다 |
| 가동률 100%를 보장하겠습니다 | 안정적인 운영에 기여하겠습니다 |
| 혁신하겠습니다 | 개선 가능성을 찾고 제안하겠습니다 |
| 반드시 리드하겠습니다 | 책임 있게 역할을 넓혀가겠습니다 |
| 세계 최고가 되겠습니다 | 직무 전문성을 꾸준히 쌓겠습니다 |

## 6. 작성 전 체크리스트

- 문항이 묻는 핵심을 첫 문장에 답했는가?
- 기업/JD 요구역량과 내 경험이 직접 연결되는가?
- 수치가 `claim-guard.md`의 공식 수치와 일치하는가?
- 미래 성과를 보장하는 표현이 들어가지 않았는가?
- 기술 용어가 직무 이해에 필요한 만큼만 쓰였는가?
- 마지막 문장이 직무 기여로 닫히는가?
