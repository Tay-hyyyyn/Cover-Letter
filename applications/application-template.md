## 6. 최종 검수 체크리스트

- [ ] 문항의 질문에 첫 문장에서 답했다.
- [ ] JD 핵심 업무와 사용자 경험이 직접 연결된다.
- [ ] 수치 표현은 `profile/claim-guard.md`와 일치한다.
- [ ] 미래 기여 문장에 `100%`, `완벽`, `보장`, `반드시` 같은 표현이 없다.
- [ ] 공개 합격자소서를 참고한 경우 구조만 참고했고 문장을 복제하지 않았다.
- [ ] 글자수 제한을 넘지 않았다.
- [ ] 마지막 문장이 직무 기여로 닫힌다.
