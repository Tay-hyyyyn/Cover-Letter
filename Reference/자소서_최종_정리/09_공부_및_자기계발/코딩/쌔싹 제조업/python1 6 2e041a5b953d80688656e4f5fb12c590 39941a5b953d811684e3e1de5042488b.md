### **Part 1: 파이썬 기초 문법**

- **자료형과 변수**: 변수는 값을 담는 이름표이며, 정수(`int`), 실수(`float`), 문자열(`str`), 불리언(`bool`) 등의 자료형이 있습니다1.
- **컨테이너 (데이터를 담는 그릇)**:
- **리스트(`list`)**: `[1, 2, 3]` 형태. 수정 가능(Mutable), 순서 있음2.
- **튜플(`tuple`)**: `(1, 2, 3)` 형태. **수정 불가능(Immutable)**, 순서 있음3.
- **딕셔너리(`dict`)**: `{'key': 'value'}` 형태. 키(Key)와 값(Value)의 쌍4.
- **집합(`set`)**: `{1, 2, 3}` 형태. 중복 허용 안 함, 순서 없음5.
- **제어문**:
- **조건문(`if`)**: 조건에 따라 코드 실행 분기 (`if`, `elif`, `else`)6.
- **반복문(`for`, `while`)**: 특정 코드를 반복 실행. `for`는 범위가 정해져 있을 때, `while`은 조건이 참일 때 주로 사용7.
- **리스트 컴프리헨션**: `[x**2 for x in nums if x > 0]` 처럼 반복문과 조건문을 한 줄로 작성하여 리스트 생성8.
- **함수(`def`)**: 코드를 재사용하기 위해 묶어놓은 블록. 매개변수, 반환값(`return`)이 핵심9. `lambda`를 이용해 익명 함수를 만들 수 있음10.
- **클래스(`class`)**: 데이터(속성)와 기능(메서드)을 묶은 설계도. `__init__` 메서드로 초기화하며, `self`는 객체 자신을 가리킴11.

### **Part 2: 데이터 분석 (NumPy & Pandas)**

- **NumPy (`np`)**:
- **`ndarray`**: 수치 계산에 최적화된 다차원 배열. 모든 원소가 같은 자료형이어야 함12.
- **생성**: `np.array()`, `np.arange()`, `np.linspace()` 등으로 생성13.
- **특징**: 반복문 없이 배열 전체에 연산을 적용하는 **벡터화 연산** 지원14.
- **조작**: `reshape`으로 모양 변경, `astype`으로 자료형 변환15.
- **Pandas (`pd`)**:
- **Series**: 인덱스를 가진 1차원 데이터 (엑셀의 한 열과 유사)16.
- **DataFrame**: 행과 열로 이루어진 2차원 표 데이터17.
- **데이터 선택**:
    - **`loc`**: 이름(Label) 기반 인덱싱 (예: `df.loc['row_name']`)18.
    - **`iloc`**: 위치(Integer Position) 기반 인덱싱 (예: `df.iloc[0]`)19.

**1. 자료형 (Data Types) : 데이터를 담는 형식**
데이터를 성격에 따라 **단순(스칼라)**과 **복합(컨테이너)**으로 구분합니다.
• **단순 자료형**: 정수($1$), 실수($1.0$), 문자열($'s'$), 불($True/False$)로 구성됩니다.
• **복합 자료형(컨테이너)**:
◦ **리스트(`[]`)**: 순서(인덱스)가 있고 수정이 가능하며, `append`/`remove`로 데이터를 넣고 뺍니다.
◦ **튜플(`()`)**: 순서는 있지만 **수정이 불가능**합니다.
◦ **집합(`{}`)**: 중복을 허용하지 않습니다.
◦ **딕셔너리(`{키:값}`)**: 이름표(키)를 붙여 데이터를 저장하며, `items()`, `keys()`, `values()`로 내용을 확인합니다.
• **정렬(Sort)**: 숫자는 크기순, 문자열은 사전순으로 정렬됩니다.
• **Pandas와의 연결**: 리스트는 위치 기반 인덱스, 딕셔너리는 이름 기반 인덱스로 연결되어 Pandas Index의 기초가 됩니다.

### 2. 제어문 (Control Statements) : 코드의 흐름 조절

상황에 따라 실행을 달리하거나 반복하는 문법입니다.

- **조건문(`if`)**: `if`, `elif`, `else`를 사용하여 조건(T/F)에 따라 코드 블록을 실행합니다.
- **삼항 연산자**: `값1 if 조건 else 값2` 형태로 한 줄로 간단히 쓸 수 있습니다.
- **반복문**:
- **`for`**: 정해진 범위(리스트, `range` 등) 내에서 반복 실행합니다.
- **`while`**: 조건이 참인 동안 계속 반복 실행합니다.
- **리스트 컴프리헨션**: `[원소 for 변수 in 범위 if 조건]` 형태로 리스트를 내포하여 빠르게 생성할 수 있습니다.
- 예: `[i*2 for i in range(1, 11) if i % 2 == 0]`

### 3. 변수와 복제 (Variables & Copy) : 메모리 관리

변수가 실제 값을 가리키는 방식과 복사할 때 주의할 점입니다.

- **참조 바인딩**: `b = a`라고 하면 새로운 데이터를 만드는 게 아니라, **똑같은 메모리 주소**를 가리키게 됩니다(별명만 하나 더 생기는 셈). 따라서 `b`를 바꾸면 `a`도 같이 바뀝니다.
- **얕은 복사 (Shallow Copy)**: 껍데기만 새로 만들고 내부 구조는 유지하는 방식입니다.
- 방법: `b = a.copy()` 또는 `b = a[:]`.
- **참조 반복**: `a = [[1,2], [3,4]]` 처럼 중첩된 구조에서 `b = a * 2`를 하면 내부 리스트까지 완전히 독립적으로 복사되지 않을 수 있으니 주의해야 합니다.
