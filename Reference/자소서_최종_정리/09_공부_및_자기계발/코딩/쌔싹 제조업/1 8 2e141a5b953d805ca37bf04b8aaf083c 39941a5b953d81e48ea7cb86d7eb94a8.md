### ❓ 문제 1. 데이터 추출 (Regex & Extract)

`Log_Message` 컬럼에서 **온도 값(숫자)**만 추출하여 `Temperature`라는 새로운 실수형(float) 컬럼을 만드세요.

- **힌트**: ‘Temp:’ 뒤에 오고 ‘C’ 앞에 있는 숫자(소수점 포함)를 찾아야 합니다.
- **사용 함수**: `.str.extract()`, `.astype()`
- **⬇️ 정답 코드 (여기를 클릭하세요)**
    
    Python
    
    `# 정규표현식 설명:
    # (?<=Temp: ): ‘Temp:’ 라는 글자가 앞에 있어야 함 (후방탐색)
    # (.): 숫자.숫자 형태를 찾아서 캡처 그룹()으로 추출
    # (?=C): 뒤에 ’C’가 있어야 함 (전방탐색) -> 없어도 되지만 더 정확함

    sensor_df[‘Temperature’] = sensor_df[‘Log_Message’].str.extract(r’(?<=Temp: )(.)’).astype(float)

### ❓ 문제 2. 조건부 필터링 (Bitwise Operator)

위에서 만든 `sensor_df`를 이용하여 다음 두 가지 조건을 **모두** 만족하는 행(Row)만 뽑아내세요.

1. `Location`이 ‘Zone A’ 이거나 ‘Zone B’ 인 데이터
2. `Temperature`가 50도 미만인 데이터
- **힌트**: `isin()` 또는 `str.contains()`와 비교 연산자, 그리고 비트 연산자(`&`)를 사용하세요.
- **⬇️ 정답 코드 (여기를 클릭하세요)**
    
    Python
    
    `# 조건 1: Zone A 또는 Zone B (isin 사용 권장)
    cond1 = sensor_df[‘Location’].isin([‘Zone A’, ‘Zone B’])
    
    # 조건 2: 온도 50 미만
    
    cond2 = (sensor_df[‘Temperature’] < 50)
    
    # 두 조건 동시 만족 (비트 연산자 & 사용 필수!)
    
    result = sensor_df.loc[cond1 & cond2, :]
    
    print(result)`

### ❓ 문제 3. 데이터 구간화 (Binning)

`Pressure` (압력) 데이터를 기준으로 3개의 등급으로 나누어 `Risk_Level`이라는 새로운 컬럼을 만드세요.

- **구간 기준**:
- 10.0 초과 ~ 11.0 이하: **‘Low’**
- 11.0 초과 ~ 13.0 이하: **‘Mid’**
- 13.0 초과 ~ 20.0 이하: **‘High’**
- **힌트**: `pd.cut()` 함수를 사용하고, 구간의 시작점은 데이터의 최소값보다 작게 설정하는 팁(`2` 기억나시죠?)을 응용하거나 정확한 구간을 입력하세요.
- **⬇️ 정답 코드 (여기를 클릭하세요)**
    
    Python
    
    `# bins 설정: 시작점(10.0), 구간1(11.0), 구간2(13.0), 끝점(20.0)
    # labels 설정: 구간 개수보다 하나 적게 (3개)
    
    sensor_df[‘Risk_Level’] = pd.cut(
    x=sensor_df[‘Pressure’],
    bins=[10.0, 11.0, 13.0, 20.0],
    labels=[‘Low’, ‘Mid’, ‘High’]
    )
    
    print(sensor_df)`
