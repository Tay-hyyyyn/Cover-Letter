## 1. Pandas (데이터 조작)

### 🔹 핵심 개념

- **Axis (축)의 방향**
- `axis=0`: **행(Row)** 방향 (▼ 위에서 아래로, 중력 방향). 데이터 축약(Mean, Sum)이나 행 삭제에 사용.
- `axis=1`: **열(Column)** 방향 (▶ 좌우로). 컬럼을 합치거나 연산할 때 사용.
- **데이터 구조의 위계 (Assembly)**
- **List**: 부품 (단순 나열, `[1, 2]`)
- **Series**: 라인 (인덱스가 붙은 1차원 데이터, `df['컬럼']`)
- **DataFrame**: 완성된 설비 (Series가 결합된 2차원 표)

### 🔹 데이터 필터링 & 가공

- **isin()**: 리스트에 있는 값만 쏙 골라내기. (SQL의 `IN`과 동일)
- `df[df['팀'].isin(['A', 'B'])]`
- **assign()**: 새로운 컬럼 생성 (메서드 체이닝 용이, 원본 보존).
- **특징**: 컬럼명에 따옴표(`''`)를 쓰지 않음 (파이썬 키워드 인자 규칙).
- `df.assign(새컬럼 = lambda x: x['A'] + x['B'])`
- **shift(-1)**: 시계열 데이터에서 ’다음 행’의 값을 현재 행으로 끌어올리기.

### 🔹 데이터 조회 (Indexing)

- **loc**: **이름(Label)** 기준. `df.loc[행조건, ['열이름']]`
- **iloc**: **순서(Integer)** 기준. `df.iloc[0:5, 0:2]` (끝번호 포함 X)

## 2. SQL (데이터베이스)

### 🔹 쿼리 작동 순서 (중요!)

> 🏗️ 공정 순서: 원재료(FROM) → 불량선별(WHERE) → 조립(GROUP BY) → 그룹선별(HAVING) → 출하(SELECT)
> 
> 1. **FROM**: 테이블 가져오기
> 2. **WHERE**: 행 단위 필터링 (집계 전)
> 3. **GROUP BY**: 끼리끼리 묶기
> 4. **HAVING**: 그룹 단위 필터링 (집계 후, 예: 평균 연봉 5천 이상)
> 5. **SELECT**: 컬럼 선택 및 출력
> 6. **ORDER BY**: 정렬

### 🔹 주요 키워드

- **GROUP BY**: Split(나누고) - Apply(집계하고) - Combine(합치는) 과정.
- **DISTINCT**: 중복 제거 (고유값 확인).
- **LEFT JOIN**: 왼쪽 테이블 기준 (오른쪽 매칭 안 되면 `NULL`).

## 3. Python Core (프로그래밍 기초)

### 🔹 함수와 변수

- **변수 vs 객체**: 변수는 주소를 가리키는 **‘이름표’**, 객체는 메모리에 있는 **‘실체’**.
- **Mutable vs Immutable**:
- `List`, `Dict`: 가변 (내용 수정 가능, 주소 유지).
- `Int`, `Str`, `Tuple`: 불변 (수정 불가, 값 바뀌면 주소도 바뀜).
- **def vs lambda**:
- `def`: 복잡한 로직, 재사용 목적. 반드시 **`return`이 있어야 값을 반환함.
- `lambda`: 한 줄짜리 일회용 함수. `return` 없이 결과가 바로 반환됨. (주로 `apply`, `assign` 내부에서 사용)

### 🔹 제어문

- **if - elif - else**: **상호 배타적**. 위에서 참(True)이 나오면 밑에는 쳐다보지도 않고 탈출함.

## 4. 커리어 & 도메인 지식

### 🔹 QA vs QC

- **QA (Quality Assurance)**: **과정(Process)** 중심. 결함 예방, 시스템 구축. (AI/데이터 분석 활용도 높음 ⭐️ 추천)
- **QC (Quality Control)**: **결과(Product)** 중심. 제품 검사, 불량 선별. (측정/실험 위주)

### 🔹 엔지니어링 마인드셋

- **추상화 (Abstraction)**: 자주 쓰는 데이터는 **변수**로, 자주 쓰는 로직은 **함수**로 정의하여 재사용성을 높인다.
- **데이터 타입 준수**: 문자열(`str`)과 숫자(`int`)는 연산 불가. 사전에 `info()`로 타입 확인 필수.
