Domain Shift 는 학습한 모델과 실제 사용 데이터의 도메인이 다른 것

preprocessing(전처리)

deduplication - 외우기 쉬운 데이터 구조를 줄여 일반화를 줄여줌

PII Filtering(개인정보 제거) - 안전 법적 리스크 감소

모델이 단순히 암기했는지 아닌지 실제 일반화 능력을 검증한다. - split

트레인 셋에 테스트 셋이 섞이는 것 - leakage

text data (이산기호) - 연속값이 아닌 이산

아날로그를 디지털로 변환하면

양자화를 진행한다 - 높은 정밀도의 이산적인 값으로 근사하여 표현

coding - 0과1의 이진법 수로 정리

subword tokenizer

1 BPE 가장 직관적이고 절리 쌍을 직접

special token

문장의 시작점과 종료점을 알리는 특수 토큰

transformer를 활용하여 병렬처리를 하고 GPU를 활용한다.

self attention - 의미를 찾는데 중요한 가중치를 스스로 찾기

Split - 데이터 셋을 Train Set 과 Test Set으로 나눠서 진행

모델을 학습시키기 위한 Train Data와

모델의 성능 암기인지 아닌지 or 일반화 능력은 좋은지 를 파악하기 위한 Test Set으로 나눠서 데이터를 사용한다.

Leakage - Split 된 데이터가 Train 과 Test 사이에서

tokenization이란

언어 모델에 입력하는 최소 단위

언어마다 word boundary가 애매하다(한국어 중국어등)

토큰화 하면 모델 성능 비용 안정성을 확보 가능

단어 보다 작고 문자보단 큰 형태의 subword를 사용
