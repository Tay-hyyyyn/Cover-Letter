# 데이터베이스

숫자는 문자 수는 값

엑셀은 공유가 되지만 여러사용자가 수정하는게 어렵다.

SQL = 씨퀄

관계형 데이터베이스 = RDBMS, Hadoop(병렬처리)

dictionally = 데이터인데 키와 값으로 묶음

json = 문자열인데 키와 값으로 묶음

두 개의 테이블을 묶는것을 머지, 조인(병합)

행은 고객, 상품, 주문 = 엔티티entity

instance = 클래스로 만든 객체

열은 해당 엔티티의 특서

기본키(pk) 중복안되고 존재해야하는 열을 각행의 기본키라한다.

열 = 필드 속성 특성 변수

여러 테이블을 연결할때 기준이 되는 열을 외래키(조인키)라하고 pk를 주로 사용하지만 아닌경우 있음

예시(금융)

계정계host 실시간 라이브러리로 살아있음 = 접속권한 극도로 제한

정보계 = 데이터 웨어하우스라 불림, 목적에 맞게 가공정제 된 걸 데이터 마트

대외계 = 타은행 및 다른 곳으로 송금 업무

metadata = 데이터에 대한 데이터 (ex 사진을 찍으면 사진 아이폰으로 찍었다, 언제 찍었다, 어디서 찍었다), 테이블 정의서

데이터마트 = DB 구매팀, 영업팀, 조달팀 데이터마트가 각각 존재한다.

데이터마트로 분석 리포트 머신러닝 수행

각 테이블마다 pk가 다르고 각 특성가지고 테이블마다 비교 및 호환 가능

데이터 스키마

1:m 관계에 대한 이해

테이블확장이 가능하다.

각행(엔티티), 테이블이 여러가지인데 여러 테이블을 조인해서 분석이 가능하다.

특성이 여러가지이면 조인이 편하게 가능하다.

데이터 분석가에겐 삽입 삭제 수정 권한을 주지않고 조회만

데이터 베이스 관리자는 모두 가지고 있음

데이터 분석가에게 view나 index권한이 있으면 좋다

sql기본문법

select 표현식 AS(alias)(별명)

where 조건식 테이블 상의 조건에 일치하는 특징을 필터링하라

group by 필드명(범주형)

having 조건식 집계한(select) 결과에서 조건지정
