# 파이썬 코드 사전

### **1. 데이터 조회 및 파악**

- `df.head(n)`: 상위 n개의 행을 조회하여 데이터 생김새 확인 (기본 5개).
- `df.info()`: 행/열 개수, 데이터 타입, 결측치 유무 등 데이터 구조 요약 확인.
- `df.shape`: `(행 개수, 열 개수)` 튜플을 반환하여 데이터 규모 파악.
- `df.columns`: 모든 열(Column) 이름 리스트 확인.
- `df['col'].unique()`: 해당 열에 존재하는 고유값(중복 제거) 확인.

### **2. 데이터 선택 및 필터링**

- `df.loc[행조건, 열조건]`: **이름(Label)** 기준으로 특정 데이터 선택 및 필터링 (가장 강력함).
- `df.iloc[행번호, 열번호]`: **위치(Integer)** 기준으로 데이터 선택 (0부터 시작).
- `df.isin([값1, 값2])`: 특정 값 리스트에 포함되는 데이터만 필터링.

### **3. 데이터 정제 (Cleaning)**

- `df.dropna(axis=0)`: 결측치(NaN)가 있는 행을 삭제 (axis=1이면 열 삭제).
- `df.fillna(값)`: 결측치를 특정 값(평균, 0 등)으로 채우기.
- `df.drop_duplicates(subset='열')`: 특정 열을 기준으로 중복된 행 제거 (병합 전 필수).
- `df.astype({'열': 타입})`: 데이터 타입을 강제로 변환 (예: float -> int).
    
    pd.to_datetime()
    

### **4. 데이터 변형 및 병합**

- `df.rename(columns={'구': '신'})`: 특정 열의 이름을 딕셔너리 형태로 변경.
- `df.assign(새열=계산식)`: 원본 유지하며 새로운 파생변수 열 생성.
- `pd.merge(df1, df2, on='키', how='left')`: 두 데이터프레임을 공통 열(Key) 기준으로 병합.
- `pd.concat([df1, df2])`: 두 데이터프레임을 위아래(axis=0) 또는 좌우(axis=1)로 단순 연결.

### **5. 문자열 처리 (String)**

- `df['열'].str.contains('패턴')`: 특정 글자나 패턴이 포함되었는지 확인 (필터링용).
- `df['열'].str.replace('구', '신')`: 특정 글자나 패턴을 다른 글자로 치환.
- `df['열'].str.split('구분자')`: 문자열을 구분자 기준으로 쪼개기 (expand=True 시 표로 확장).
