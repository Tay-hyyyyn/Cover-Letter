일반화 능력 - 보편적인 데이터의 패턴을 파악하는 능력

지도학습 - 정답(label)이 있는 데이터로 학습하는 것

- 분류가 있을때 많이 사용한다.
- 틀리면 더 많은 학습이 필요하다.
- 에러는 모델의 예측값과 정답값과의 차이
- 에러를 최소화한다.

비지도학습 - 정답이 없는 데이터로 학습

- 거의 이용하지 않고 표현만 한다.(사실 준지도 학습)

준지도학습 - 정답이 있는 일부 데이터와 정답이 없는 대량의 데이터를 학습

- 라벨링(ex의사) 비용이 비쌀 경우 활용

강화학습 - 에이전트가 환경 속에서 시행착오를 통해 보상을 최대화 하는 행동

- 에이전트 : 학습하고 행동하는 주체
- 환경 : 에이전트가 상호작용하는 세계
- 보상 : 특정 행동에 대한 피드백
- 행동 : 에이전트가 특정 상태에서 하는 선택
- 에이전트의 행동을 최적화하는 것이 목적이고, 모델의 에러 최소화가 목적이다.

서버가 과부하로 인해서 다운이 되면 어떻게 해결하는가?
