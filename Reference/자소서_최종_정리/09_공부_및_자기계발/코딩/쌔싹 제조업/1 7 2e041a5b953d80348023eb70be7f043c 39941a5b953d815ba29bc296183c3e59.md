# 2. 🐍 Python & Pandas 핵심 문법 정리

### 📊 데이터 선택과 필터링 (Indexing)

| **구분** | **문법 예시** | **설명 및 비유** |
| --- | --- | --- |
| **불리언 인덱싱** | `df[df['P'] > 100]` | **조건 검색**. “압력이 100 넘는 데이터만 필터링해.” (안쪽 `[]`는 조건 마스크 생성) |
| **loc** | `df.loc[:, 'Temp']` | **이름(Label) 기준**. “온도(Temp)라는 이름표가 붙은 열 가져와.” (끝번호 포함) |
| **iloc** | `df.iloc[:, 3]` | **위치(Integer) 기준**. “3번째 칸에 있는 열 가져와.” (끝번호 제외, 반복문에 유리) |

### 🛠 데이터 가공 (Processing)

- **정렬**: `df.sort_values(by='Price', ascending=False)` (내림차순 정렬)
- **형변환**: `df['Price'].astype(int)` (문자열을 숫자로 변환해야 연산 가능)
- **순위**: `df['Rank'] = df['Price'].rank(ascending=False)`
- **문자열 처리**: `df['Addr'].str.contains('강남')` (특정 단어 포함 여부 확인)

### 🧬 변수의 복제 (Memory Management)

- **참조 (`b = a`)**: 별명만 붙임. `b`를 바꾸면 `a`도 바뀜. (공동 문서 작업)
- **얕은 복사 (`b = a.copy()`)**: 껍데기만 복사. 내부 리스트 수정 시 원본 영향 있음.
- **깊은 복사 (`deepcopy`)**: 완벽한 분리. (완전히 새로운 설계 도면)

# 4. 🌐 API 데이터 수집 (Web Scraper)

### 🏗 수집 구조 (Pagination)

- **`numOfRows`**: 한 번에 가져올 데이터 양 (그릇 크기). 가능한 크게(9999) 잡는 게 유리.
- **`totalCount`**: 전체 데이터 양.
- **전략**: 전체 개수를 확인하고 페이지를 넘겨가며(`loop`) 수집.

### ⚡ 최적화된 수집 코드 (Best Practice)

> 핵심: 반복문 안에서 매번 합치지 말고, 리스트에 모았다가 한 번에 합칠 것 (concat).
> 

Python

`data_list = [] # 빈 바구니 준비

for code in area_codes:
# 1. 데이터 요청
df = get_api_data(code)
# 2. 바구니에 담기 (속도 빠름)
data_list.append(df)

# 3. 마지막에 한 번에 합치기 (메모리 효율)

final_df = pd.concat(data_list, ignore_index=True)`

### 🚨 주요 에러 해결 (Troubleshooting)

- **`TypeError: 'NoneType'...`**: 데이터가 없는 경우. `if df is not None:`으로 방어 코드 작성.
- **`SyntaxError: unicodeescape`**: 파일 경로 역슬래시(`\`) 문제. `r'경로'`로 해결.
- **무한 루프(처럼 보일 때)**: `tqdm`으로 진행률 시각화, `time.sleep()`으로 API 과부하 방지.
