## 1. 🐍 Python & Pandas 심화

### 🔹 Axis (축)의 방향성

> 기계공학 비유: axis=0은 중력 방향(세로), axis=1은 횡방향(가로)
> 
> - **`axis=0` (Index)**: **행(Row)**을 따라 **위에서 아래로** 연산. (데이터 쌓는 방향)
> - `df.mean(axis=0)`: 컬럼별 평균 (세로로 훑음)
> - `df.drop(0, axis=0)`: 0번 행 삭제
> - **`axis=1` (Columns)**: **열(Column)**을 따라 **왼쪽에서 오른쪽으로** 연산.
> - `df.sum(axis=1)`: 한 행 내의 데이터 합계 (가로로 훑음)
> - `df.drop('col', axis=1)`: 특정 열 삭제

### 🔹 Lambda (람다) 함수

> 핵심: “이름 없는 일회용 함수”. def와 달리 소괄호 ()를 쓰지 않음.
> 
> - **문법**: `lambda 매개변수 : 표현식` (return 없이 결과가 자동 반환됨)
> - **활용 예시 (apply와 결합)**:Python

```
`# 1. 제곱 계산
df['force_sq'] = df['force'].apply(lambda x: x**2)

# 2. 조건부 로직 (if-else 한 줄 쓰기)
# 문법: 값(True) if 조건 else 값(False)
df['status'] = df['score'].apply(lambda x: 'Win' if x > 5 else 'Loss')

# 3. 문자열 가공 (MLB 팀 코드 만들기)
# 입력: 'Dodgers_2025' -> 출력: 'DOD'
df['code'] = df['info'].apply(lambda x: x.split('_')[0][:3].upper())`
```

### 🔹 데이터 불변성 (Immutability)과 `assign`

> 원칙: 원본 데이터를 덮어쓰지 말고(In-place X), 새로운 복사본을 만들어라.
> 
> - **`df['A'] = ...`**: 원본을 직접 수정 (가변 방식).
> - **`df.assign(A = ...)`**: 원본은 두고, 수정된 **새 데이터프레임**을 반환 (불변 방식, 추천).Python

```
`# assign을 이용한 체이닝(Chaining) 기법
df_new = df.assign(
    diff = lambda x: (x['home'] - x['away']).abs(),  # 절댓값 차이
    win  = lambda x: x['home'] > x['away']           # 승패 여부
)`
```

### 🔹 리스트 슬라이싱 (Slicing)

> 규칙: [이상 : 미만] (시작은 포함, 끝은 미포함)
> 
> - **문법**: `data[start : end]`
> - **개수 계산**: `end - start` (손으로 셀 필요 없음)Python

```
`s = 'PythonProgramming'
print(s[6:10])
# 결과: 'Prog' (6, 7, 8, 9번 인덱스 추출)
# 길이: 10 - 6 = 4글자`
```

### 🔹 메모리 구조 (변수 vs 객체)

- **변수(Variable)**: 객체의 **주소(Address)**를 담고 있는 이름표.
- **객체(Object)**: 실제 메모리에 존재하는 **값(Value)**.
- **주소 변경 규칙**:
- **불변 객체(int, str, tuple)**: 값 수정 불가 → 수정 시 **새 주소**로 이사 감.
- **가변 객체(list, dict)**: 값 수정 가능 → 수정해도 **주소 유지** (내용물만 바뀜).

## 2. 💾 SQL (데이터베이스)

### 🔹 쿼리 작성 순서 vs 실행 순서

> 작성 순서: SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY
> 

| **키워드** | **역할** | **필수 짝꿍 / 특징** |
| --- | --- | --- |
| **`FROM`** | 데이터 창고 | 테이블 이름 |
| **`WHERE`** | **원재료 선별** | 개별 행(Row) 필터링. **가장 먼저 실행됨.** |
| **`GROUP BY`** | **조립/뭉치기** | 부서별, 팀별로 묶을 때 사용. |
| **`HAVING`** | **제품 검수** | **`GROUP BY` 된 결과(평균, 합계)**를 필터링. |
| **`SELECT`** | 최종 출력 | `*` (전체) 또는 특정 컬럼. `CASE WHEN` 사용 가능. |

### 🔹 조건 키워드 구분 (혼동 주의)

- **`WHERE`**: “연봉 3000 이상인 **사람**” (개별 행 O, 집계 함수 X)
- **`HAVING`**: “평균 연봉 5000 이상인 **부서**” (개별 행 X, 집계 함수 O)
- **`CASE WHEN`**: “3000 이상이면 ‘A’, 아니면 ’B’로 **표시**해라” (필터링 X, 값 변환 O)
- **`IF`**: SQL 표준에서는 조회 조건으로 쓰지 않음 (주로 값 변환 함수로 존재).

### 🔹 테이블(Table) vs 행렬(Matrix)

- **행렬**: 수치 연산을 위한 2차원 배열 (인덱스로 접근).
- **테이블**: **헤더(이름표)**가 있고 다양한 타입(문자, 숫자, 날짜)이 섞인 **스마트한 행렬**.
