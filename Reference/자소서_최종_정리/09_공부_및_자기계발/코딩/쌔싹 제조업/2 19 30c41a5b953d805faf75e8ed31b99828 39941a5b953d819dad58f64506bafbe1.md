EDA (Exploratory Data Analysis) : 데이터 탐험가

- **필요 역량:**
- **데이터 시각화:** `matplotlib`, `seaborn`, `plotly` 등을 다루는 능력.
- **통계적 사고:** 분포, 상관관계, 가설 검정에 대한 기본 지식.
- **도메인 이해력:** 주어진 데이터(예: 의료, 제조, 금융)의 배경지식을 빠르게 습득하는 능력.
- **주요 할 일 (To-Do):**
- 타겟 변수(정답지)의 분포 확인 (분류 문제인지 회귀 문제인지, 데이터 불균형은 없는지 파악).
- 결측치(빈칸)와 이상치(비정상적으로 크거나 작은 값) 탐지 및 리포팅.
- 변수 간의 상관관계(Correlation) 분석을 통해 모델링에 유리한 힌트 찾기.
- 분석 결과를 문서화하여 Feature Engineer와 Modeler에게 아이디어 제공.

Feature Engineering : 데이터 연금술사

- **필요 역량:**
- **데이터 핸들링:** `pandas`, `numpy`를 자유자재로 다루는 능력.
- **전처리 기법 이해:** 스케일링(표준화/정규화), 인코딩(문자를 숫자로 변환)에 대한 높은 이해도.
- **창의성:** 기존 변수들을 조합해 새로운 파생 변수를 만들어내는 아이디어.
- **주요 할 일 (To-Do):**
- 결측치를 논리적인 값으로 채우기 (평균으로 채울지, 다른 변수를 활용해 예측해서 채울지 결정).
- 숫자 범위가 다른 변수들의 스케일 맞추기 (`StandardScaler`, `MinMaxScaler` 등).
- 문자형(범주형) 데이터를 기계가 이해할 수 있는 숫자로 변환.
- 불필요한 변수를 제거하고, 모델의 성능을 끌어올릴 핵심 변수만 추려내기(Feature Selection).

### Modeler : 모델 건축가 🏗️

준비된 데이터를 재료 삼아, 목적에 맞는 최적의 머신러닝 알고리즘을 선택하고 성능을 극한으로 끌어올리는 역할입니다.

- **필요 역량:**
- **알고리즘 지식:** 로지스틱 회귀부터 트리 기반 모델(XGBoost, LightGBM, Random Forest)의 원리와 장단점 파악.
- **최적화 툴 사용:** `Optuna`나 `GridSearchCV`를 활용한 하이퍼파라미터 튜닝 능력.
- **평가 지표 이해:** 대회 규칙에 맞는 평가 지표(Accuracy, R2, ROC AUC 등)를 정확히 이해하고 검증 셋(Validation Set)을 구성하는 능력.
- **주요 할 일 (To-Do):**
- 교차 검증(Cross-Validation) 전략 세우기 및 훈련/검증 데이터 분리.
- 가벼운 베이스라인(기본) 모델부터 앙상블(여러 모델을 섞는 기법)까지 다양한 모델 실험.
- 검증 데이터를 활용해 조기 종료(Early Stopping) 규칙을 설정하고, 모델이 훈련 데이터에만 과적합(Overfitting)되지 않도록 방어.
- 최종 예측 결과를 만들어 Supervisor에게 전달.
