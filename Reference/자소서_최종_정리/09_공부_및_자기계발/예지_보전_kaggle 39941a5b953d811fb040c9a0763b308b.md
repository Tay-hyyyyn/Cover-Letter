# 예지 보전 kaggle

## **1. 핵심 접근 전략 (Key Strategies)**

이번 대회에서 가장 효과적이었던 4가지 핵심 기법입니다.

### **① 도메인 지식 기반 파생 변수 생성**

| **파생 변수** | **산출 공식** | **도메인 의미** |
| --- | --- | --- |
| **temp_diff** (과열 정도) | `공정 온도 - 공기 온도` | 열 방출 실패(Heat Dissipation Failure)와 직접 관련. 온도차가 클수록 냉각 시스템 이상 |
| **power** (기계 부하) | `회전 속도 × 토크` | 실제 기계가 소비하는 동력. Power Failure 탐지의 핵심 지표 |
| **power_torque_ratio** (과부하 지수) | `토크 / 회전 속도` | 높은 토크 + 낮은 RPM 조합은 과부하 운전을 의미 → Overstrain Failure 감지 |
| **tool_wear_torque** (누적 피로도) | `공구 마모 시간 × 토크` | 마모된 공구에 높은 토크가 가해지면 고장 위험 급증 → Tool Wear Failure 탐지 |
| **log_power** (스케일 보정 동력) | `log(1 + power)` | power의 큰 값 영향을 억제하여 트리 모델의 분할 안정성 향상 |

### **② UDI를 시계열 인덱스로 활용한 시간 패턴 추출**

UDI(고유 식별자)가 단순 ID가 아닌 **시간 순서를 반영하는 인덱스**임을 파악하고, 이를 기반으로 시계열 파생 변수를 생성했습니다.

| **파생 변수 유형** | **대상 피처** | **설명** |
| --- | --- | --- |
| **Rolling Mean** (10건 이동평균) | 공기 온도, 공정 온도, RPM, 토크 | 최근 트렌드 반영 (온도 서서히 상승 = 냉각 이상 징후) |
| **Rolling Std** (10건 이동표준편차) | 공기 온도, 공정 온도, RPM, 토크 | 변동성 측정 (센서 값 불안정 = 이상 징후) |
| **Diff** (직전 대비 변화량) | 공기 온도, 공정 온도, RPM, 토크 | 급격한 변화 감지 (토크 갑자기 급증 = 과부하) |

> **왜 효과적인가?:** 고장은 대부분 **갑자기** 발생하지 않고 사전 징후가 있습니다. Rolling 피처는 “서서히 악화되는 상태”를, Diff 피처는 “갑작스러운 이상”을 포착합니다.
> 

### **③ Failure Type 제거를 통한 Data Leakage 방지 (보수적 접근)**

test.csv에 Failure Type이 존재하지만, 이 컬럼은 Target(고장 여부)의

**파생 정보**이므로 data leakage 위험이 있다고 판단하여**제거**했습니다.

> **전략적 판단:** Failure Type을 피처로 쓰면 ROC 점수가 크게 올라갈 수 있으나, 실제 운영 환경에서는 고장 유형을 사전에 알 수 없으므로 모델의 일반화 성능을 위해 제거하는 보수적 접근을 선택했습니다.
> 

### **④ 4-모델 가중 평균 앙상블**

단일 모델의 한계를 극복하기 위해 **4개 Gradient Boosting 모델**의 예측 확률을 합산했습니다.

```

최종 예측 = (w₁ × XGBoost) + (w₂ × LightGBM) + (w₃ × CatBoost) + (w₄ × HistGBT)
가중치 wᵢ = 해당 모델의 CV ROC-AUC / 전체 모델의 CV ROC-AUC 합
```

| **모델** | **가중치** | **역할** |
| --- | --- | --- |
| CatBoost | 0.2502 | Ordered Boosting으로 과적합 방지, 최고 단일 AUC |
| XGBoost | 0.2501 | L1/L2 정규화 기반 강건한 분할 |
| LightGBM | 0.2499 | Leaf-wise 분할로 다른 패턴 학습 |
| HistGBT | 0.2498 | sklearn 내장, 안정적 기본 성능 |

> **왜 효과적인가?:** 4개 모델이 각각 다른 분할 전략(level-wise vs leaf-wise vs ordered)을 사용하므로, 서로 다른 패턴을 학습합니다. 앙상블은 개별 모델의 약점을 상호 보완하여 OOF 기준 **+0.001** 향상을 달성했습니다.
>

## **2. 데이터 전처리 및 모델링 디테일**

### **클래스 불균형 처리**

정상 데이터가 고장 데이터보다 **약 28.5배 많은** 극심한 불균형(96.6% vs 3.4%)을 해결하기 위해 각 모델별로 다른 기법을 적용했습니다.

| **모델** | **불균형 처리 방식** | **적용 값** |
| --- | --- | --- |
| XGBoost | `scale_pos_weight` | 28.5 (= 9661/339) |
| LightGBM | `scale_pos_weight` | 28.5 |
| CatBoost | `auto_class_weights` | `'Balanced'` (자동 계산) |
| HistGBT | `class_weight` | `'balanced'` (자동 계산) |

### **범주형 변수 인코딩**

제품 등급(Type: L/M/H)에 대해 **Ordinal Encoding** (L=0, M=1, H=2)을 적용했습니다.

- **왜 One-Hot이 아닌가?:** L < M < H는 품질 등급의 순서가 있으므로 ordinal이 트리 모델에서 더 효율적이며, 차원 증가를 방지합니다.

### **교차 검증 전략**

소수 클래스(고장)가 fold마다 균등하게 분배되도록 **StratifiedKFold(n_splits=5)** 를 사용했습니다.

- **왜 일반 KFold가 아닌가?:** 고장 데이터가 339건(3.4%)밖에 없으므로, 일반 KFold를 쓰면 특정 fold에 고장 데이터가 0개가 될 수 있어 ROC-AUC 계산 불가능

### **전처리 파이프라인 흐름**

```

원본 데이터 (7개 피처)
  ↓ 불필요 컬럼 제거 (Product ID, Num ID, Failure Type)
  ↓ Type Ordinal 인코딩 (L=0, M=1, H=2)
  ↓ 물리 기반 피처 +5 (temp_diff, power, ratio, wear×torque, log_power)
  ↓ UDI 시계열 피처 +12 (rolling mean/std/diff × 4개 피처)
  ↓ 컬럼명 정리 (XGBoost 호환: 특수문자 제거)
최종 23개 피처
```

## **3. 결과 및 회고**

### **최종 성과**

| **지표** | **값** |
| --- | --- |
| 최고 단일 모델 (CatBoost) | **ROC-AUC 0.98017** |
| OOF 앙상블 (가중 평균) | **ROC-AUC 0.98121** |
|  |  |

### **핵심 인사이트**

1. **도메인 지식의 힘:** 센서 데이터를 다룰 때, 알고리즘 성능에만 의존하기보다 데이터의 도메인(기계적 특성)을 이해하고 접근하는 것이 성능 향상에 큰 도움이 되었습니다. 특히 `temp_diff`, `power`, `tool_wear_torque`는 물리적 고장 메커니즘을 직접 반영하는 변수로, 모델이 더 쉽게 고장 패턴을 학습할 수 있었습니다.
2. **시계열 시각의 가치:** UDI를 단순 ID로 버리지 않고 시간 인덱스로 활용함으로써, rolling/diff 기반의 시계열 피처 12개를 추가로 확보했습니다. 고장의 “사전 징후”를 포착하는 데 효과적이었습니다.
3. **앙상블의 안정성:** 4개 모델의 가중 평균 앙상블은 개별 최고 모델 대비 0.001 향상이라는 작지만 일관된 개선을 보였습니다. Kaggle에서는 소수점 이하의 차이가 순위를 결정하므로 의미있는 개선입니다.

# **Kaggle 예측 유지보수(Predictive Maintenance) 대회 - 데이터 분석 전략 보고서**

## **1. 데이터 무결성 확보 및 안정적 전처리 (Data Integrity & Preprocessing)**

- **방향성:** 실제 산업 현장에 즉시 배포 가능한 강건한 모델 설계 및 극심한 클래스 불균형(3.4%) 통제.
- **근거 및 기술:**

**Data Leakage 차단:** 정답을 유추할 수 있는 미래 정보인 `Failure Type`을 과감히 제거하여, 예측 모델 본연의 일반화 성능을 확보했습니다. (ROC 점수의 손해를 감안)

**순서형 인코딩:** 제품 등급(`Type`)은 L < M < H 형태의 물리적 강도 순서를 가지므로, 트리 모델의 효율적인 분할을 위해 One-Hot 대신 Ordinal Encoding을 적용했습니다.

**계층적 교차 검증:** 소수 클래스의 누락을 막고 검증의 신뢰도를 높이기 위해 `StratifiedKFold(5-Fold)`를 채택했습니다.

---

## **2. 물리 법칙 및 시계열 기반 피처 엔지니어링 (Domain & Time-Series Engineering)**

- **방향성:** 기계 설비의 작동 원리와 시간 경과에 따른 열화 메커니즘을 알고리즘이 이해할 수 있는 수치로 변환.
- **근거 및 기술:**

**파생 피처:** 냉각 시스템 이상을 반영한 `temp_diff`(과열), 모터 출력 공식 기반의 `power`(과부하), 마모도와 하중을 결합한 `tool_wear_torque`(누적 피로도) 등 물리적 고장 원인을 직접 타기팅하는 변수를 생성했습니다.

| **파생 변수** | **산출 공식** | **타기팅 고장 유형** |
| --- | --- | --- |
| `temp_diff` | 공정 온도 − 공기 온도 | Heat Dissipation Failure |
| `power` | 토크 × 회전 속도 | Power Failure |
| `power_torque_ratio` | 토크 / 회전 속도 | Overstrain Failure |
| `tool_wear_torque` | 공구 마모 × 토크 | Tool Wear Failure |
| `log_power` | log(1 + power) | 스케일 보정 (모델 안정성) |

**시계열(UDI) 패턴 추출:** UDI를 단순 식별자가 아닌 공정 시간 순서로 재해석했습니다. 10건 단위의 이동 평균(Rolling Mean/Std)과 직전 대비 변화량(Diff)을 계산해 ’서서히 누적되는 스트레스’와 ’급작스러운 센서 튐 현상’을 동시에 포착했습니다.

---

## **3. 다중 분할 전략을 활용한 모델 앙상블 (Multi-Model Ensemble)**

- **방향성:** 특정 알고리즘의 편향을 상쇄하고 예측의 극단적 튀어오름(Outlier)을 방어하여 최종 스코어 안정화.
- **근거 및 기술:**

**알고리즘 다양성 확보:** 분할 방식이 각기 다른 4개의 부스팅 모델(CatBoost, XGBoost, LightGBM, HistGBT)을 병렬로 구성해 데이터 패턴을 다각도에서 학습했습니다.

**불균형 맞춤 제어:** 각 모델의 특성에 맞춰 `scale_pos_weight` 및 `balanced` 파라미터를 세밀하게 조정했습니다.

**가중 평균 앙상블:** 최고 성능을 낸 CatBoost에만 의존하지 않고, 각 모델의 교차 검증(CV) ROC-AUC 점수에 비례하여 가중치를 부여하는 앙상블을 수행했습니다.

| **모델** | **튜닝 전 AUC** | **가중치** | **분할 전략** |
| --- | --- | --- | --- |
| CatBoost | 0.98017 | 0.2502 | Ordered Boosting |
| XGBoost | 0.98000 | 0.2501 | Level-wise |
| LightGBM | 0.97893 | 0.2499 | Leaf-wise |
| HistGBT | 0.97879 | 0.2498 | Histogram-based |

> **기본 파이프라인 성과:** OOF 앙상블 ROC-AUC **0.98121**
>

## **4. 마할라노비스 거리를 활용한 숨겨진 이상치 탐지 (Mahalanobis Distance)**

- **방향성:** 데이터 상으로는 ’정상(No Failure)’이지만 실제 센서 값은 비정상적으로 튀는 노이즈 데이터를 탐지.
- **근거 및 기술:**

완전한 정상 데이터(Target=0)들의 **다변량 분포(평균, 공분산)**를 구한 뒤, 모든 데이터가 정상 중심으로부터 물리적으로 얼마나 떨어져 있는지 `mah_distance` 점수를 계산해 변수로 추가했습니다.

```

사용 피처: 공기 온도, 공정 온도, RPM, 토크, 공구 마모, temp_diff, power (7차원)
계산: 정상 데이터의 공분산 행렬 기반 다변량 거리
결과: 거리가 클수록 → 정상 분포에서 이탈 → 잠재적 고장 징후
```

> **왜 효과적인가?:** 개별 피처로는 정상 범위 내이지만, 다변량 관점에서는 비정상인 숨겨진 이상치를 포착합니다. 예를 들어, 온도와 RPM이 각각은 정상이지만 “이 조합”은 비정상인 경우를 감지합니다.
> 

---

## **5. 피처 선택 및 Optuna 자동 하이퍼파라미터 튜닝 (Feature Selection & Auto-Tuning)**

- **방향성:** 노이즈 피처 제거로 모델 집중도를 높이고, 체계적 탐색으로 수동 튜닝의 한계 극복.
- **근거 및 기술:**

**피처 중요도 기반 선택:** LightGBM의 split 기반 중요도를 평가하여 하위 5개 피처를 제거했습니다. 중요도가 낮은 피처는 노이즈만 추가하여 과적합을 유발하므로, 24개에서 19개로 집중도를 높였습니다.

**Optuna 자동 튜닝:** 3개 모델(XGBoost 50 trials, LightGBM 50 trials, CatBoost 30 trials)에 대해 Bayesian Optimization 기반의 파라미터 탐색을 수행했습니다.

| **모델** | **튜닝 전** | **튜닝 후** | **향상폭** |
| --- | --- | --- | --- |
| XGBoost | 0.98000 | **0.98512** | **+0.005** |
| LightGBM | 0.97893 | **0.98505** | **+0.006** |
| CatBoost | 0.98017 | **0.98160** | **+0.001** |

## **6. Stacking 앙상블을 활용한 메타 러닝 (Stacking Ensemble)**

- **방향성:** 단순 가중 평균을 넘어, 메타 러너가 각 모델의 예측을 최적으로 조합하는 2층 구조 구축.
- **근거 및 기술:**

```

┌─────────────────────────────────────────────────────┐
│  1층 (Base Learners)                                 │
│  XGBoost (AUC 0.985) → OOF 확률                      │
│  LightGBM (AUC 0.985) → OOF 확률       → 메타 피처   │
│  CatBoost (AUC 0.982) → OOF 확률                      │
├─────────────────────────────────────────────────────┤
│  2층 (Meta Learner)                                  │
│  Logistic Regression → 최종 예측                      │
└─────────────────────────────────────────────────────┘
```

**왜 Logistic Regression을 메타 러너로?** 1층이 이미 복잡한 패턴을 학습했으므로, 2층은 과적합 위험이 낮은 단순 모델이 적절합니다. LR은 확률 보정(calibration)이 우수하여 ROC-AUC에 유리합니다.

**자동 전략 선택:** Stacking이 단순 평균보다 낮을 경우 자동으로 단순 평균을 선택하는 방어 로직을 구현했습니다. (실험 결과 단순 평균 0.985 > Stacking 0.981)
